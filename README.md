# SmartHire

## AI-Powered Resume Screening and Job Matching System

SmartHire is an AI-powered resume screening and job matching system that analyzes resumes against job descriptions using Natural Language Processing and Machine Learning techniques.

### Features

- Upload a resume in PDF format
- Enter a job description
- Extract and clean resume text
- Identify relevant skills and keywords
- Calculate resume-job match score
- Display matching results visually
- Uses TF-IDF and Cosine Similarity

### Technologies Used

- Python
- Streamlit
- Natural Language Processing (NLP)
- Machine Learning
- Scikit-learn
- NLTK
- PyPDF2
- Matplotlib

## How It Works

1. Upload a resume PDF.
2. Enter the job description.
3. SmartHire processes the resume and job description.
4. Text is cleaned using NLP techniques.
5. TF-IDF converts text into numerical vectors.
6. Cosine Similarity calculates the matching score.
7. Results are displayed on the web interface.
